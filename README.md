uTool – P2P Equipment Rental System

PROJECT DESCRIPTION

UTool is a web-based P2P Equipment Rental System that allows users to manage tools and handle rental transactions. It provides a platform where tool owners can list their available tools, while other users can browse available tools and submit rental requests.

The system includes user authentication, tool management, rental requests, and lending management. It also allows tool owners to manage rental requests by approving or updating their rental status.

6. Update db.php with the online MySQL credentials provided by InfinityFree.

# uTool - P2P Equipment Rental


## Project Description

uTool is a web-based Equipment Rental System that allows users to list their tools for rent, browse available tools, and manage rental transactions.

## Technologies Used

- PHP
- MySQL
- HTML
- CSS
- JavaScript
- XAMPP
- Git and GitHub

## Main Features

- User Registration and Login
- Tool Listing and Management
- Tool Rental Requests
- Rental Approval and Management
- Lending Management
- Rental Transaction Tracking
